# TradeMap Explorer

Локальный инструмент для выборки торговой статистики ITC TradeMap и выгрузки её в Excel.

Повторяет сценарий сайта — страна, продукт, партнёр, импорт/экспорт, месячные ряды,
показатель Quantity — но позволяет выбрать **несколько** стран и продуктов за один
прогон и складывает всё в одну книгу Excel.

Для установки на сервер см. **[DEPLOY.md](DEPLOY.md)** — Docker, HTTPS и вход по паролю.

## Быстрый старт (локально)

```bash
cd ~/Desktop/trademap
./run.sh
```

Первый запуск сам создаст виртуальное окружение, поставит зависимости и скопирует
`.env.example` в `.env`. Затем откройте <http://127.0.0.1:8765>.

## Вход

Вход выполняется **учётной записью trademap.org** — своей регистрации у
инструмента нет. Логин и пароль проверяются прямо в TradeMap: пускаем тех,
кого пускает он.

Пароль нигде не сохраняется — он сразу обменивается на токен доступа. На диск
(`.cache/tokens/`) ложатся только access- и refresh-токены, по отдельному файлу
на каждого пользователя; в имени файла хеш логина, а не сам логин. Дальше токен
обновляется сам, пока действует refresh. Кнопка «Выйти» удаляет и сессию,
и сохранённые токены.

Запросы к TradeMap идут от имени вошедшего — значит, доступ к месячным рядам
и лимиты зависят от его учётной записи, а не от общей.

`.env` для этого не нужен: там задаётся только домен (на сервере) и, по желанию,
`TRADEMAP_SESSION_SECRET`.

### Диагностика из командной строки

```bash
.venv/bin/python -m app.auth --check
```

Спросит логин и пароль (или возьмёт `TRADEMAP_USERNAME`/`TRADEMAP_PASSWORD`
из `.env`, если они заданы), покажет, как получен токен, и сделает пробный
месячный запрос. Ожидаемо `HTTP 200`; `HTTP 401` означает, что учётная запись
не даёт доступа к месячным рядам.

Сбросить сохранённые токены: `.venv/bin/python -m app.auth --reset`.

## Как пользоваться

### Ветка 0713 (сушёные бобовые)

По умолчанию список продуктов ограничен группой **0713 и всем, что под ней** —
это задаётся в `.env`:

```
TRADEMAP_PRODUCT_ROOT=0713
TRADEMAP_PRODUCT_EXTRA_MAX=6
```

Уровни внутри ветки:

| Длина | Что это | Источник |
|---|---|---|
| 4 (`0713`) | группа целиком | HS, общий для всех стран |
| 6 (`071310`, `071320`, …) | 12 субпозиций: горох, нут, фасоль, чечевица, бобы… | HS, общий |
| 8 и 10 (`07131010`, `0713100001`) | национальные тарифные линии | свои у каждой страны |

Национальные коды подтягиваются **только после выбора страны**. Пока страна
не выбрана, в списке 13 общих кодов.

Над списком есть кнопки быстрого выбора — «0713 целиком», «6 знаков»,
«8 знаков», «10 знаков», «все национальные» — каждая отмечает всю глубину разом.

Чтобы вернуть весь классификатор HS, очистите `TRADEMAP_PRODUCT_ROOT=`.

#### Важно: глубина национальных кодов у стран разная

Единого «национального уровня» не существует — проверено на данных:

| Страна | Где реально лежат данные под 0713 |
|---|---|
| Индия | 8 знаков (`07131010`) |
| Австралия | **10 знаков** (`0713100001`) |
| США | **10 знаков** (`0713101000`) |

У Австралии восьмизначные коды присутствуют в классификаторе, но **пустые**:
отчётность ведётся на 10 знаках. Поэтому `TRADEMAP_PRODUCT_EXTRA_MAX` по
умолчанию равен 6 — жёсткий лимит «+4 знака» молча выбросил бы весь
национальный уровень США и Австралии.

#### Национальный уровень — один запрос вместо десятков

Выбрать 21 национальный код в режиме «Партнёры» — это 21 запрос (×2 на оба
показателя). Если разбивка по партнёрам не нужна, режим **«Продукты»** с
детализацией «национальные коды» отдаёт весь уровень **одним** обращением:

```
Режим: Продукты · Детализация HS: национальные коды · Продукт: 0713
→ 13 строк, 156 значений, 2 запроса, ~5 секунд
```

Интерфейс подсказывает это сам, когда выбрано много кодов.

**Любое обращение к национальному уровню требует входа** — даже к годовым
данным (`Access to yearly data at the NTL level requires login`). Приложение
подставляет токен автоматически.

### Порядок работы

1. **Частота** — месяц / квартал / год.
2. **Направление** — импорт или экспорт.
3. **Что перечислять в строках** — партнёры, продукты или страны. Это ось вывода:
   её значения приходят из ответа целиком, задавать их не нужно. Мультивыбор
   применяется к двум оставшимся осям.
4. **Показатель** — Value и/или Quantity. Если отмечены оба, они выгружаются вместе;
   у Quantity подставляется единица измерения из TradeMap (например, `Tons`).
5. **Страна / продукт / партнёр** — списки с поиском; у стран показан диапазон
   доступных данных для выбранной частоты.
6. **Период** — списки ограничены реальной доступностью данных выбранных стран.
7. **Показать** — превью в браузере, **Скачать Excel** — файл.

Партнёр по умолчанию — `000 World`: он даёт итоговую строку и сведения о национальном
источнике данных.

## Что внутри книги Excel

| Лист | Содержимое |
|---|---|
| `Data (wide)` | Как таблица на TradeMap: периоды по столбцам. Итоговая строка World выделена. |
| `Data (tidy)` | Одна строка на комбинацию и период — под сводные таблицы, Power Query, pandas. |
| `Query` | Все параметры выгрузки, время, национальные источники данных, встретившиеся сноски. |

Стоимость приходит в **тысячах** USD или EUR — так же, как на сайте.

## Ограничения

- **API неофициальный.** Новый TradeMap — SPA поверх `https://www.trademap.org/api`;
  эндпоинты не задокументированы и могут измениться. Все имена параметров собраны
  в одном месте — `app/client.py`.
- **Защита от нагрузки — главное ограничение.** При слишком частых запросах API
  отвечает `403 Forbidden: You have been blacklisted` и перестаёт обслуживать
  клиента. В наших замерах блокировка держалась **более получаса**; точный срок
  неизвестен, и сбросить его со своей стороны нельзя — только переждать.
  Поэтому темп в `app/config.py` сознательно низкий (2 параллельных запроса,
  пауза в секунду), а приложение, поймав 403, прекращает прогон целиком и
  сообщает об этом, вместо того чтобы продолжать долбиться.
  Практический вывод: не гоняйте выгрузки подряд без пауз и дробите большие
  выборки. Справочники кэшируются на сутки и в этот трафик не попадают, поэтому
  интерфейс продолжает открываться даже во время блокировки.
- **Предел разворота** — 200 запросов на прогон (`TRADEMAP_MAX_TASKS` в `.env`).
  Каждая комбинация «страна × продукт × показатель» — это отдельное обращение
  к API, плюс страницы пагинации. Интерфейс показывает оценку объёма и времени
  под выбором периода: например, 12 кодов × 2 показателя — это 24 запроса.
  Большие выборки надёжнее гонять частями.
- **Справочники кэшируются на сутки** в `.cache/`. Удалите папку, чтобы обновить.

## Структура

```
app/
├── config.py      настройки, .env, константы API
├── auth.py        токены TradeMap по пользователям (+ CLI --check / --reset)
├── client.py      клиент API: пагинация, троттлинг, ретраи
├── reference.py   справочники стран и продуктов с кэшем
├── query.py       разворот мультивыбора, склейка Value+Quantity
├── excel.py       сборка книги из трёх листов
├── webauth.py     вход: проверка учётки в TradeMap и сессия на cookie
├── main.py        FastAPI: REST + статика
└── static/        интерфейс (без сборки)
```

Данные принадлежат ITC Trade Map; их использование регулируется
[Terms & Conditions](https://www.trademap.org) сайта.
